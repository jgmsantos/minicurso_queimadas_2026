# Minicurso de queimadas

O minicurso utilizou os dados do Programa Queimadas do INPE. Ele foi realizado entre os dias 29 e 31 de julho de 2026.

Neste repositório estão os Jupyter Notebook que foram usados ao longo da aula 1.

Não precisa baixar nada, apenas execute os Jupyter. Informações adicionais podem ser encontradas dentro dos scripts.

Toda a documentação do curso está disponível em:
